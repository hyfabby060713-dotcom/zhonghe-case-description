# 中合村案例研究构想

16页中文 HTML 幻灯片，主题暂定，用于公共管理案例大赛团队介绍。以政策企业家理论为核心、协同治理为辅助。网页只读，无账号、编辑器、数据上传或外部运行依赖。

## 观看

双击 `index.html` 即可离线打开。使用 ← →、空格、PageUp / PageDown 翻页，Home / End 跳转首尾页，F 全屏；目录可直接跳页。手机采用单页纵向阅读。浏览器打印可输出全部页面（横向、关闭页眉页脚、开启背景图形）。

## 自己修改

- `content.js`：每个对象对应一页。修改标题 `title`、副标题 `sub`、正文 `body`、脚注 `foot`。正文支持 HTML；不要删除字符串两端的反引号。
- `styles.css`：颜色、字体、页面布局。
- `app.js`：翻页与目录；一般无需改动。
- `index.html`：网页入口。

添加或删除 `SLIDES` 中的页面对象，页码与目录会自动更新。不需要安装依赖或构建。

## GitHub Pages

将以上文件放在仓库根目录。在仓库 Settings → Pages → Build and deployment 中，选择 Deploy from a branch、main、/(root)，保存。以 GitHub 返回的网址为准。后续编辑 `content.js` 并提交，Pages 会自动更新。

## Netlify（备用）

直接上传本文件夹，或连接 GitHub 仓库。构建命令留空，发布目录为 `.`。所有文件使用相对路径，可用于 GitHub Pages 子路径。

## 内容边界

老师原始记录已读取，但不随公开仓库发布。页面区分讨论方向、公开报道、分析假设和待核实事项。“三合”完整表述、银行制度名称、136核算基数及制度化程度仍需实地确认。未使用村庄实景照片、采访原件或敏感账目。
